# 0.2.146（2026-10-13 发布）

## 变更一：配置变更实时同步到设置页（#74，现场驱动）

- 现场问题：「对话配置了管理员完全访问模式，但客户端那边看的还是没勾选」。
- 根因：配置存储有多个写入方（设置页、IM 对话 manage_access/manage_settings、导入），但 renderer 只在挂载/登录完成/设置页保存时刷新——IM 侧改的配置 UI 看不到，且此时在设置页保存会用 stale draft **反向覆盖** IM 侧的修改。
- 实现：`config:set` 统一广播 `config:changed` → renderer 重拉；设置页 draft 仅在**无未保存编辑**时才采纳外部变更（防擦掉正在输入的内容）。

## 变更二：一次性任务会话自动清理（#75，现场驱动）

- 现场问题：「任务列表很多，一次性的任务执行之后过一段时间是不是可以删掉了」——定时任务/自主任务/评测的机器会话只增不减。
- 设计：**只清机器会话**（`sched:`/`work:`/`eval:` id 前缀，从诞生不可变），**IM 对话与控制台会话永不自动删**（用户数据）；叠加 `updated_at < cutoff`，正在跑的会话绝不误删；清理复用级联删除（消息/挖掘游标无孤儿）。
- 配置：`general.oneOffRetentionDays`，设置页「通用」tab 可调，0=关闭；启动时 + 每次保存配置后执行。

## 变更三：一次性会话保留默认 30 天（用户裁定）

- `oneOffRetentionDays` 默认从 7 天提高到 **30 天**；一次性迁移：已持久化的旧默认 7 自动升级为 30，用户自设值（含 0=关闭）原样保留（4 用例钉住迁移语义）。
- 流程说明：本项改动（commit 5460d89）因操作失误**直接提交推送到了 main，未经 PR 与独立审查**（违反仓库 PR 约定，已如实记录；内容经 45 套件门禁验证，双远端一致，未做 force-push 回退）。后续以 PR 流程为准。

## 变更四：联网研究搜索引擎 UI 对齐（#76，现场驱动）

- 现场问题：「duckduckgo 国内连不上有什么用，为什么客户端配置上面还是 duckduckgo」。
- 根因：0.2.129 起后端就把任何 duckduckgo 配置强制翻成 bing（国内不可达、静默返回空），但 UI 选项和类型定义从未同步——设置页显示与实际行为脱节，UI 里也选不到真实在用的引擎。
- 修复：UI 选项改为「Bing（免 Key，国内可直连）」，类型同步；后端零改动。

## 变更五：自主任务默认不限轮数（#77，用户裁定）

- 两条自主执行链路的轮数硬上限取消：自主任务 work 窗口 15 轮、定时任务自主模式 20 轮，均改为**默认不限轮数**（`maxTurns=0`）；时长上限照旧真实生效（work 30 分钟 / 自主模式 120 分钟），到点暂停并推送。
- 保留的护栏：需要人工、执行出错、手动取消仍立即停止；停滞静默重试不变；显式传正数 `maxTurns`（上限 200）仍可设上限；既有任务的显式配置不批量改动。
- 提示词明示「本窗口不限轮数……不要因假想轮数将尽而自行停下或草草收尾」；推送文案不再出现「N/0 轮」，时间触发的暂停如实显示「已达时间上限」。
- 附带：`update_scheduled_task` 支持只传 `maxTurns` / `maxMinutes` 独立调整预算（原先必须连 autonomous 一起传）。
