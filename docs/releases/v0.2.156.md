# v0.2.156

## 自主任务韧性：窗口加长 + 超时自动顺延（#100）

现场：spay 7 天对账巡检每次都超时——纯扫描就要 25-30 分钟，30 分钟窗口装不下；旧语义超时即暂停等管理员，窗口白跑、什么都没推成。

- **默认工作窗口 30 → 90 分钟**（`DEFAULT_WINDOW_BUDGET`）。
- **超时自动顺延**：窗口到点不再 `waiting_human` 等管理员恢复，改为自动顺延 5 分钟后继续，推送说明交接状态。覆盖三个出口：循环内时间检查、send 后 stopReason 检查（此分支原先会把超时吞成暂停）、异常路径。
- **连续超时熔断**：连续 2 次顺延仍未完成才转人工，提示管理员调大 `max_minutes` 或拆分任务——「永远顺延」比暂停更糟的静默空转被挡住。`timeout_streak` 持久化（含旧库迁移），只数**连续**超时：正常收尾（NEXT_CHECK/DONE/人工交接/熔断暂停）即清零。
- **窗口提示词教分段**：先扫描落盘 → 逐项处理 → 一次性推群；剩余时间装不下未完部分就写 NEXT_CHECK 顺延，不把半成品推成群。

## IM 渠道可观测性 + 能力声明 + 调度幂等（#98）

- **渠道健康度状态卡**：`IMAdapter.status()` 五字段（connected/lastConnectedAt/lastError/lastErrorAt/reconnectAttempts），钉钉全链路打点；设置页新增「渠道状态」卡，30s 自动刷新，IM 关闭时停轮询。
- **能力声明**：`IMAdapter.metadata`（displayName + capabilities 四布尔），manager 按 `proactive` 能力门控主动推送——不支持主动消息的渠道不再误发。
- **调度幂等**：`SchedulerRunCtx{runId, isTimedOut()}`；inFlight 守卫持有到 run 真正 settle，防 losing run 叠跑双推；迟到推送带「迟到结果」注解，过期结果不冒充新鲜。
