# v0.2.154

## run_command 同步超时 60→300 秒 + 客户端自主任务删除

### 修复：run_command 同步超时（现场 2026-10-18）

Nova 用同步方式跑对账 playwright 脚本，60 秒硬超时必然被杀，随后反复原样重试（每次白跑一分钟）。

- **`capabilities.shell.timeoutSec` 默认 60 → 300 秒**（后台进程仍默认不限时）。升级安全：已显式配置的值不动，只兜底缺省键
- **工具描述前置硬超时警示**：同步默认 300 秒；预计更久**一律** `background=true`；**被超时强杀后不要原样重试**（改后台跑，或把脚本改成分段/增量可续）；点名 playwright、数据拉取、大批量文件处理这类几乎必然超时的场景直接后台
- 同步上限 300s < 回合看门狗 20min，命令必先到自己的上限，不会被看门狗误杀

### 新增：客户端删除自主任务

- 设置页 → 任务 → 自主任务：终态（已完成/已取消）任务可删除，**需确认弹窗**（明示永久删除不可恢复）；进行中的任务不能删（先在 IM 或客户端取消，删执行中任务等于杀掉在飞窗口）
- 删前安全论证：无 FK 引用 work_items；done 时的学习产物在完成瞬间已独立写入知识库，任务行到终态就是纯历史
- 顺手补 #88 漏接线：`workItemAct`（暂停/恢复/取消）与编辑弹窗在 renderer 里从未被触发——列表行一个按钮都没有。本次按任务状态补齐按钮组，并修掉「终态任务编辑假报成功」（setField 对终态零变更却返回 truthy）
