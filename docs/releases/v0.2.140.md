## 0.2.140（2026-10-08 统一发布）

（现场反馈，0.2.139 的续篇）

- 根因：✕/关闭只清本地状态、**不取消引擎侧登录流程**——流程每次推送状态（授权链接/设备码/提示）都会把刚关掉的对话框重新弹开，表现为「关不掉」；且推送处理器无条件 setLogin，对话框关着也会被弹开；
- 修复：① 关闭 = 本地清除 + 取消引擎流程（推送随之停止）；② 推送处理器改为函数式更新——对话框处于关闭状态时忽略推送（挂载时的 authLoginStatus 恢复机制不受影响，重进设置页仍能看到进行中的登录）；
- 「取消登录」按钮行为不变（真正中止流程并显示已取消终态页）；
- 复审处置（0H/0M/2L）：L2 挂载恢复改为 setLogin(prev => prev ?? state)（迟到的 status 响应不回退显示）；L1（cancel 不同步清 activeAuthLogin 的窄竞态，已自愈但可再弹一次终态页）记 follow-up——根治在 engine 侧 cancel 时同步 finish+清指针。

### 变更：核心规则升级为「不确定先查库、再问人」（用户提问驱动：内置 prompt 是否强制待确认问题先查知识库）

- 此前核心规则只对「事实/流程类」强制先查知识库；「需裁定/不确定怎么处理」类只要求**直接问人**——模型可以完全跳过知识库，沉淀过的卡点经验永远吃不到（现场「同一坑反复踩」的 prompt 层根因）；
- 现改为两级强制：**先 search_knowledge_base 查沉淀过的经验/判定标准 → 查不到再明确提问**；kb 关闭时核心规则降级为「先用可用工具自行查证」，不再引用未注册工具（capabilityRules 的 learn/research 教学行与 memoryLines 的同型问题记 follow-up）；
- 顺手修复：默认核心规则里「不确定就问」「上报是兜底」各重复注入两次——重复注入稀释 LLM 规则遵从度，已去重；
- 守护测试同步：test-prompt 新增强制查库/去重/kb 门控断言（immutable 已按流程 re-pin）。

### 变更：工作项瞬断分级静默重试（现场驱动：网关瞬断直接弹「执行出错」）

- 现场闭环：工作项恢复执行后正常跑了 25 秒，模型网关（LiteLLM）瞬断——引擎即时重试 1 次仍断 → 工作项立即进入「执行出错」暂停打扰管理员（2026-10-08 11:47 实录）；
- 修复：工作项运行窗口对引擎「无回复产出」类信号（error/deterministic）做分级静默退避重试（60s/120s，与定时链 stall 分级同源），耗尽才走「执行出错（静默重试仍失败）」暂停；重试轮不消耗轮次预算；
- **throw 异常绝不重试**（任意异常直接暂停）；deterministic-without-error（流被掐、只剩罐头道歉文本）此前会被当正常回复白烧预算——纳入重试信号后一并修复；
- 泄密纪律：重试日志不携带错误内容；catch 兜底文案按「重试耗尽 vs 从未重试」拆分，不再对 throw 路径谎称「静默重试仍失败」；
- 复审处置（1H/1M/2L 全修）：H1 退避等待期间 stop/cancel/超时落地后不得补发整轮（session.abort() 对 idle agent 是 no-op）；M1 重试信号与定时链如实标注「deliberately WIDER」；L1 退避定时器真实挂起断言；L2 文案拆分；
- 守护用例改写：「throw 绝不重试；error/deterministic 走分级重试（user ruling 2026-10-08）」——答案保留/释放清理/泄密不外渗断言全保留。

### 变更：引擎瞬断重试改 10 次递增退避（用户裁定：参考 Claude Code / zcode 重试逻辑）

- 「立即重试 1 次」扛不过多秒级网关瞬断 → 改为最多 10 次退避重试：1s→2s→4s→8s→16s→32s→60s×4（封顶），总自愈窗口约 5 分钟，期间不打扰用户；11 次尝试全失败才走诚实错误上报；
- 对所有场景生效：工作项、定时任务、IM/控制台对话；
- 每轮迭代重读错误状态（首版把陈旧错误带进后续迭代导致成功后仍重试——被新行为测试抓到后修复）；退避期间喂看门狗活性时钟（单跳 60s << 默认 20 分钟阈值，无误杀）；
- 复审处置（1H/2M/3L 全修）：H1 /stop 走 abortSession 不 markTurnAbort——退避窗口内停机会被无视并照常补发请求，修复为 abortSession 统一 mark in-flight turn；M1 不可恢复的上下文溢出即止（否则白烧 10 轮×每轮一次压缩 LLM 调用）；M2 退避窗口对 isIdle/abortAllTurns 可见（install_now/自动更新不再误判空闲）；L1/L2/L3 记 follow-up；
- telemetry：重试从布尔改计数（下游兼容）；
- 新增 test-engine-retry.mjs（真引擎 + 可脚本化 Agent stub，5 用例：退避表 pin / 瞬断被吸收 / 持续耗尽 / stop 落在退避内不补发 / 退避窗口可中断）。
