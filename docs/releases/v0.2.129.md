## 0.2.129

### 新增：`[[REMEMBER: …]]` 立即沉淀标记（现场反馈「探索很久找到解法就该立刻记录，上下文压缩会忘掉」）

自主任务协议新增第三个标记：模型在**找到可行方案的那一刻**单独写一行 `[[REMEMBER: 一句话经验]]`，运行器立即写入知识库（saveLearned，同题自动合并），IM 侧同步一条「📌 已沉淀经验」确认，然后任务继续——**不停链、不等任务结束、不等上下文压缩**。

- 回合协议新增教学行：「经过多轮尝试终于找到可行方案的那一刻立即沉淀，宁可多记不可漏记」（kbSearch+kbLearn 双门控，与既有标记一致）；
- 标记行从推送文本中剥离；与 TASK_DONE/NEED_HUMAN 共存时 kind 判定不变、remember 照常提取；
- 沉淀走 saveLearned（低置信、待复核、同题合并），不会污染已批准知识。

配合 0.2.128 的任务完成自动沉淀（done 收尾轮），形成「过程发现立即记 + 任务完成兜底记」双层沉淀。

### 修复

- **研究引擎迁移 v2**：duckduckgo 在大陆不可达，任何仍指向它的配置（legacy 默认、或经 capabilities 开关开启时 engine 未动）统一翻转为 bing——此前「开了研究但永远返回空」的静默失效状态一并修复。
