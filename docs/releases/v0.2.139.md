## 0.2.139

### 修复：「取消登录」点了没反应（现场反馈）

- 根因：取消是 fire-and-forget——`authLoginCancel()` 返回 false（引擎侧已无活动流程，如上一次登录结束后的残留对话框）或 IPC 抛错时都被静默吞掉，对话框永远停在等待页，没有任何可见反馈；
- 修复（两处接线）：① 主进程 handler 丢弃 `engine.authLoginCancel()` 的 boolean 返回值、恒返 true（0.2.130 onError 丢参同型——渲染层改什么都是死代码）；② 渲染层取消是 fire-and-forget，false/异常被吞、对话框永远停在等待页。现 handler 透传返回值；渲染层读取结果——真正中止走「登录已取消」终态页，无事可做/失败则本地关闭对话框，取消期间按钮禁用防双击；
- 引擎侧中止链路（abort → callback server 拒绝 → cancelled 事件）经核查完好，本次不涉及。
