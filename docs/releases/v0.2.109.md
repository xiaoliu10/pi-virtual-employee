## 0.2.109

### 修复

- **长任务心跳兜底把 prompt 脚手架当「当前请求」展示**（现场 2026-10-03：推送显示「当前请求：【系统注入的真实执行时间：…】」）。定时任务/工作窗口/自主链的存储用户消息 = 调度器注入的合成前缀 + 真实任务文本；心跳旁路的 LLM 总结失败回退到确定性兜底时，锚点取原文截断 60 字符后恰好只剩前缀。现在锚点提取前剥离全部三类合成前缀：定时任务时间前缀、工作窗口脚手架（取【目标】/【工作项】行作任务身份）、自主链协议块（取真实任务 prompt）；普通用户文本原样透传。
- **心跳推送双 ⏳**：自主链推送点对已带 ⏳ 的汇报不再重复添加表情。
