# v0.2.149

## 内核迁移：接入 pi-coding-agent（AgentSession 包裹方案）

VE 的会话内核从裸 `pi-agent-core` Agent 升级为 **Agent 外包 pi-coding-agent 的 AgentSession 会话壳**——保留 VE 自建 Agent 的全部现场加固（工具/模型/streamFn/压缩口径/退化门禁/重试梯子），新增扩展运行时（插件宿主）与 pi 脚手架。

**关键事实**：`AgentSessionConfig.agent` 即 pi-agent-core 的 `Agent`——包裹式而非换循环，facade API 与 orchestrator 零改动。

### 新增

- **内核**：`src/engine/imports.ts`（pi runtime 唯一动态 import 出口）、`src/engine/session-host.ts`（自建 Agent 包 AgentSession 壳；pi 自带 auto-retry/auto-compaction 显式关闭）、`src/engine/tools/tool-adapter.ts`（AgentTool→ToolDefinition 适配）
- **runtime 分发**：`src/runtime/bootstrap.ts`（引导器）+ `resources/pi-runtime-lock/`（随安装包内置的 lockfile，钉 pi-coding-agent 1.2.0 全树 119 包）；运行时由引导器在用户机器上从 npmmirror→Gitee→npmjs 源链安装到 userData，版本自检（ELECTRON_RUN_AS_NODE + 防版本谎报 env 清理）+ runtime.json 原子写；失败留在 legacy 不带病启动
- **灰度开关**：`general.engineKernel`（默认 `legacy`，零现场影响；`pi-session` 启用新内核）+ `general.piRegistryUrl`（自定义源）
- 设计文档：`docs/design/ve-pi-session-migration.md`

### 改

- `src/engine/engine.ts`：`ensureHost` 懒建壳 + `driveTurn` seam（session.prompt vs agent.prompt）+ `abortDriven` 双层（session.abort 停 settle 循环）+ hosts 生命周期（rebuild/dropSession/resetSession/invalidate 全 dispose）；修复 rebuild 分支 hosts 泄漏
- `electron/main.ts`：启动时按 `engineKernel` 引导 pi runtime；失败回退 legacy
- 依赖：`@earendil-works/pi-agent-core` / `pi-ai` 1.1.0 → 1.2.0（typecheck 零破坏）；`pi-coding-agent` 仅 devDependency（不进打包产物）

### 现场行为保持

- VE 的 ~30 内置工具（知识库/remember/work/scheduler/computer/shell…）全部保留在自建 Agent 上；pi 自带编码工具（read/bash/edit/write）被 `initialActiveToolNames: []` 显式挡在门外
- 压缩口径（CJK token 估算 0.2.67、两道闸门 0.2.93、切点 0.2.69/0.2.80、输出上限 0.2.95）与 #83 退化门禁全部保留——pi 自带的 auto-retry/auto-compaction 已关闭，VE 的梯子与闸门是唯一决策者
- 会话亲和、scoped memory 注入、心跳进度总结、历史/保留清理、登录态/凭据、RBAC 全部保留

### 测试

+3 套件 10 用例：`test-session-host`（真依赖集成：包壳/工具执行/扩展事件/内置抑制）、`test-pi-session-kernel`（端到端：legacy 零壳/pi-session 全链路/工具遥测存活/rebuild 无泄漏）、`test-runtime-bootstrap`（源链/校验/原子）。全量 50 套件 + typecheck + build + 13 immutable。

### 灰度

`general.engineKernel` 默认 `legacy`，现场零影响。切 `pi-session` 后扩展运行时启用——pi-quality-gates 等 pi 插件可直装（插件生态对接为后续 PR）。
