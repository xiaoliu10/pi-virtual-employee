## 0.2.108

### 改进

- **管理员门控简化：恢复任务不再需要确认口令**（#24，现场反馈：管理员被连续要求确认多次，门控疲劳）。任务等待人工时，管理员在来源会话**直接回复答复内容**（验证码、预计解决时间等）即可恢复，员工带着答复继续；不再要求念「确认继续」口令。
  - 安全边界不变：仅限来源会话中经过平台验证的**实时管理员**；非管理员、无身份、定时任务身份、默认 admin 角色一律拒绝（`确认创建` 口令保留——它是启动无人值守执行的唯一显式授权动作）。
  - 同步清理全部残留口令指引（暂停回执、状态标签、工具描述、推送文案、文档），避免新旧指引互相矛盾。
