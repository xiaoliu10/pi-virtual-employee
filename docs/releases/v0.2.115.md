## 0.2.115

### 新增

- **供应商账号登录**：设置 → 自定义模型 → 账号登录。支持订阅账号 OAuth 直连（无需 API Key）：OpenAI ChatGPT 账号（Plus/Pro）、Anthropic Claude Pro/Max、Kimi Coding Plan（设备码）、GitHub Copilot、xAI SuperGrok、OpenRouter、Meta；Z.ai Coding Plan 提供 API Key 录入 + 套餐额度查询。
- **凭证与 pi CLI 共享**：存 `{agentDir}/auth.json`（`PI_CODING_AGENT_DIR` 优先，默认 `~/.pi`）——登录一次三端（CLI/Desktop/虚拟员工）通用；跨进程文件锁 + 原子写 + 0600，与 pi CLI 并发安全。
- **Supplier 账号化**：`authProvider` 供应商的模型列表从目录一键预填，无需填 API Key/BaseURL；请求时凭证由 pi-ai Models 解析，OAuth 过期自动带锁刷新；过期/未登录时对话内给出「去 设置 → 账号登录 重新登录」的中文引导。
- 登录弹窗支持授权 URL 跳转（系统浏览器，`setWindowOpenHandler` 默认 deny + https 白名单）、设备码展示、API Key/选择项输入；外部窗口一律走 shell.openExternal。
