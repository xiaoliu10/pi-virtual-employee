# v0.2.159

## 修复

### 预签名 URL 豁免收窄到参数级 + host 白名单（v0.2.158 的安全回归）

v0.2.158 的预签名放行以**整条 URL**为粒度且只看参数名存在性，独立 code review 探针实证可被哑标记逃逸：凭据 URL 拼上 `&OSSAccessKeyId=x&Signature=y` 即整条免检——Gitee PAT 明文出群、内网密码 URL 从整条拦下回归为明文。

- 豁免收窄为授权本体参数的完整赋值（`OSSAccessKeyId`/`Signature`/`X-Amz-Signature`/`X-Amz-Credential` 的 name+value），同 URL 其他凭据参数照常脱敏/拦截
- host 白名单：仅 `*.aliyuncs.com` / `*.amazonaws.com`
- 检测掩码改为删除赋值整段（值级掩码会被 `credential` label 词命中，等长填充字节落入 shape 值字符类）
