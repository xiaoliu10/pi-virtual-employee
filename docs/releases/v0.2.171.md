# v0.2.171 — 自主任务执行期进度汇报 + 任务/会话节奏分离

## 现场问题

自主任务（工作项）窗口动辄执行几十分钟，期间**零汇报**，只有窗口结束才推一次；且进度汇报节奏只有 `longTaskProgressMin` 一个参数，IM 会话轮次和长任务共用——想给任务设 30 分钟一报，就只能把会话轮次也改成 30。

## 变更

1. **自主任务窗口接入进度汇报**：复用 v0.2.162 的旁路总结机制（不占上下文、不计入 transcript），窗口开始即汇报，窗口结束停止并等在途推送落定后再发完成报告——「⏳ 进行中」永远不会晚于「✅ 完成」到达
2. **两个参数分开配置**：
   - `longTaskProgressMin`（默认 15）——IM 会话轮次节奏
   - `taskProgressMin`（默认 30）——定时任务与自主任务节奏
3. 汇报目标：任务来源会话优先，无来源则创建人单聊；静默任务保持静默
4. 设置页两个独立输入框，保存后立即生效

## 测试

3 条新增（参数独立性 / 窗口汇报生命周期时序 / 异常窗口不泄漏汇报器）+ 变异验证；全量 67 套件、typecheck、build、immutable 通过。
