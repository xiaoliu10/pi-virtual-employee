# 0.2.143（2026-10-09 发布）

## 变更：定时任务静默执行开关（现场驱动：保活任务每 5 小时推「⏰ 定时任务完成+报告链接」是噪音）

- 需求：不是所有任务执行完都需要推送。保活/巡检类维护任务成功即是常态，完成通知是噪音——且该推送是框架层（main.ts scheduler runner）行为，prompt 无法控制，需要产品级开关；
- 实现：`scheduled_tasks` 新增 `silent` 列（迁移 NOT NULL DEFAULT 0，既有任务保持推送语义不变）；推送统一走 `shouldPushScheduledResult` 门控——**成功不推送、出错仍推送**（静默绝不隐藏失败）；
- 覆盖两条链路（复审 H1 修正后）：
  - **单轮任务**：完成推送按门控判定，engine 执行出错（SendResult.error 非空）仍推送；
  - **自主模式**：5 处推送点全部接入门控——心跳进度/经验沉淀/轮次边界/auto-learn 沉淀属 in-flight 通知（静默即不推）；最终结果**只有纯成功 done 被静默**，human/budget/stalled/error 四类需要人工关注的结果仍然推送；
- 用户面：`create_scheduled_task` / `update_scheduled_task` 新增 `silent` 参数（确认文案如实说明「成功时不推送，出错才通知」）；`list_scheduled_tasks` 列表静默标记 + 详情推送模式展示；设置页定时任务卡片新增「静默」开关（tasks:schedSilent IPC）+ 静默徽标；renderer ScheduledTaskRow 顺带补齐与 store 漂移的字段（created_by/autonomous/max_turns/max_minutes/chain_state）；
- 审查闭环（electron-pro 子代理 1H/2M/2L 全处置）：H1 自主模式推送链路绕过门控（silent 对自主任务完全失效）→ 修复+outcome 映射测试；M2 测试死语句、L1 注释指向已修；M1 运行超时场景不推送为既有行为（runWithTimeout 超时走 tick markRun，不进 runner 推送段）记 follow-up；L2 迁移前行类型缝隙生产无风险（openDatabase 同步迁移先于 store 创建）；
- Copilot review 配额第 31 次耗尽（PR #63），子代理审查为替代路径；
- 新增 scripts/test-scheduler-store.mjs（真实 SQLite 迁移/create/update 合并/legacy 三用例）+ shouldPushScheduledResult 边界与自主 outcome 映射测试 + 工具层静默用例；41 套件 + typecheck + 13 immutable 全过。
