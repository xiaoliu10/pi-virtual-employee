# v0.2.170 — 修复模型模仿兜底文案（「执行已暂停」自我复制）

## 现场问题

群里回复「执行已暂停，请检查恢复状态。」——查库发现这次**不是代码投的，是模型自己生成的**（该回答 stop=stop、仅 12 token）。根因：前几轮故障产生的投递通知被写进对话历史，durable 把历史原样导入 transcript，模型看到自己「说过」这句话，于是照样模仿输出。**故障文案在自我复制**——不清掉就会一直冒出来。

## 修复

1. durable 导入会话历史时，剥离这类合成通知（按特征片段识别，文案日后改写仍有效）
2. 启动时一次性清理历史里的存量通知（幂等，日志报告删除条数）
3. 用户提问与真实答复全部保留，上下文不丢

## 测试

2 条新增回归 + 变异验证（匹配规则退回整句比较必失败）；全量 66 套件、typecheck、build、immutable 通过。

## 说明

这是「执行已暂停」的第四种成因。前三种（usage fault、空 completion、终态误判）已分别修复；本次起这类通知不再进入 transcript，从源头切断模仿链。
