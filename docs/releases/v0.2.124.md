## 0.2.124

### 新增：内置技能市场（现场反馈「技能下载不行吗？可以内置一下技能市场」）

- 新工具 **manage_skills**（管理员 IM 单聊）：
  - `action=market`：列出市场上可安装的技能（索引默认为本仓库 `skills-market/index.json`，可用 `manage_settings` 设置 `skills.marketUrl` 换源）；
  - `action=install`：按 name（从市场）或 url（任意 SKILL.md 的 https 直链）安装，写入走既有 SkillWriter 管线（原子写、内置技能保护、路径防越界、YAML 回读校验），装完自动重新加载立即生效；同名技能需对方明确同意后传 `overwrite=true` 才覆盖；
  - `action=remove`：移除本机用户技能（内置技能不可移除，路径防越界）；
  - `action=list`：查看已加载技能。
- **安全边界**：install/remove 走 `requireConfirmedAdmin`（管理员 + 「确认」，开启管理员完全访问后免确认——与其它管理门控同一镜像语义）；仅接受 https 直链；单文件 512KB 上限；技能名正则拒绝路径穿越。
- 上架技能：向本仓库 `skills-market/index.json` 提 PR（url 指向 SKILL.md 直链）。当前索引为空起步，配合 0.2.123 的联网研究，员工可先自行发现技能源，再由管理员 `install <url>` 落地。

### 说明

- 0.2.123 已让 `research_web` 开箱可用（默认开启 + Bing 引擎）；本版的 `manage_skills` 与之配套：搜得到 → 装得上 → `refresh_skills` 立即生效。
