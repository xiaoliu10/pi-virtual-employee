# v0.2.158

## 修复

### 群聊报告链接打不开（出站门禁误伤预签名 URL）

- **现象**：`save_report` 生成的 OSS 报告链接在群消息里打不开（`Signature`/`OSSAccessKeyId` 被替换成 `***`），私聊正常。
- **根因**：#95 出站凭据门禁把预签名 URL 的签名参数与真实凭据同列处理。预签名 URL 的 query 是访问授权本身（key id + 过期 + HMAC 签名，`AccessKeySecret` 从不进 URL），属于 bearer 凭证而非凭据泄露。
- **修复**：阿里云 OSS（`OSSAccessKeyId=`+`Signature=`）与 AWS SigV4（`X-Amz-Signature=`+`X-Amz-Credential=`）预签名 URL 原样放行；Gitee `raw_with_token` 的 `access_token`（长时效 PAT，真凭据）继续脱敏；消息内其他位置出现真凭据仍整条拦下。
