## 0.2.131

### 修复：Windows 中文环境 shell 输出乱码（现场反馈：MuMu 共享文件夹列目录输出乱码/变量丢失）

- **根因**：中文 Windows 的 cmd.exe 默认 GBK（CP936）输出，而命令输出的解码是 UTF-8——中文路径/文件名（如 `MuMu共享文件夹`）在 `run_command` 输出里必然乱码。
- **修复**：Windows 的 shell 模式执行时自动在组合命令前强制 `chcp 65001`（UTF-8 代码页）——cmd 内建命令与 powershell 输出正常；同时注入 `PYTHONUTF8=1` 修复 python 管道输出。**范围披露**：tasklist/netstat 等 System32 直连命令（绕过 cmd 的既有防引号破坏设计）与 python 之外的 ANSI 输出仍可能 GBK——这类中文输出请改用 list_directory 或脚本写文件再读（解码侧 GBK 兜底记 follow-up）。
- **工具指引**：`run_command` 描述新增——含中文/空格的路径必须整体双引号；**列目录、查文件元数据优先用 `list_directory`**（原生支持中文路径，无 shell 引号转义问题），run_command 留给真正需要执行程序的场景。
- 使用提示：要让小派能直接 `list_directory` MuMu 共享文件夹，需管理员把它加入文件系统白名单（对话：`把 C:\Users\Administrator\Documents\MuMu共享文件夹 加入 allowedDirs，确认`）。
