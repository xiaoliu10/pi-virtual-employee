# v0.2.152

## 安装包瘦身：排除未使用的官方 SDK（exe -1.37MB，退回 100MiB 红线安全区）

### 体积

- exe **100,732,927 → 99,295,043 bytes（-1.37MB）**；距 Gitee 100MiB 上传红线余量 3.87MB → **5.56MB**
- asar 解包 182MB → **162MB**（-20.4MB）

### 改动

`build.files` 排除 `@anthropic-ai/sdk`（12MB）与 `@google/genai`（8.4MB）——pi-ai dependencies 全家桶带入、VE 源码 0 引用。

### 安全性论证（实测非推断）

- pi-ai 全链路 lazy：`providers/*.js`（含 anthropic/google）引用的全是 `*.lazy.js` 变体（`lazyApi(() => import(...))`），官方 SDK 只在真正用对应 provider 发请求时才动态加载
- 实验：移走两家 SDK 后 `providers/all` 正常加载、openai-completions API 正常；全量 52 套件（含真实 pi-agent-core 链路）在 SDK 移走态全绿
- 打包复核：asar 内两家已排除，`openai`（网关必经）与 `typebox`（主入口静态 re-export）保留

### 取舍

配置 anthropic/google 官方直连会得到 ERR_MODULE_NOT_FOUND 显式报错。VE 模型服务均走网关/自建端点，国内网络对两家官方端点本就不可达，无实际损失。
