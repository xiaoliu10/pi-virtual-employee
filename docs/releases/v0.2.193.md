# v0.2.193

## English

### Chat panel UX: thinking block & resizable window

- **Thinking block reworked** (floating panel + standalone page):
  - Appears immediately when a turn starts — always ABOVE the answer, not after the first thinking event.
  - Light-gray, softly faded body text (`#a9a9ae` + 0.3px blur) so it reads as background process, not conclusion.
  - Auto-expands while thinking; auto-collapses the moment the answer text starts (not only at turn end). If thinking resumes later, it re-expands.
  - Manual open/close is respected: automatic expand/collapse only fires on phase transitions (thinking→done / done→thinking), never per-event, so a panel you opened stays open.
  - Models that never think leave no empty panel behind (mid-turn and final state both covered).
- **Resizable chat window**: drag the bottom-right grip.
  - Floating panel is anchored bottom-right — drag up/left to grow. Standalone page: drag right/down.
  - Size persists across reloads (localStorage), clamped to a sane minimum (300×360 floating / 360×420 page) and to the viewport, so a shrunk window can never strand the panel.
  - Keyboard accessible: focus the grip and use arrow keys. Private-mode (no localStorage) only loses persistence, not resizing.

### Background-task pushes & escape hatch

- **Push headers now follow origin**: a chat-dispatched task (Router triage moved a chat message to background) pushes as 「后台任务阶段进展 / 完成 / 需要人工」 instead of 「自主任务…」 — mined/proposed items keep the original label. Field 2026-11-05: a chat-dispatched rerun of a scheduled task's failed run pushed as autonomous, which read as if the cron itself had gone autonomous.
- **The 「前台执行」 escape hatch is real**: replying 「前台执行」 cancels your own queued/scheduled chat-dispatched item and re-runs the original instruction inline (creator-only; a working window is refused honestly to avoid double execution; the re-run skips plan-ahead and triage). The ACK advertises it again — it was dropped earlier because the mechanism did not exist yet.

### Quality

- New behaviour suites drive the REAL served page scripts with real fetch/SSE streams and pointer events (10 page-channel + 8 resize + 5 floating-channel assertions); 6 mutation rounds all red.
- Background-task push headers follow origin (chat-dispatched → 后台任务), and the 「前台执行」 escape hatch converts queued/scheduled chat-dispatched items back to an inline run of the original instruction.
- 110 test suites green; immutable core (16 regions) unchanged.

## 中文

### 聊天面板体验：思考块与可拖拽窗口

- **思考块重做**（浮窗 + 独立页双通道）：
  - 回合开始即出现，始终在回答上方——不再等第一条思考事件。
  - 正文浅灰虚化（`#a9a9ae` + 0.3px blur），读感是「背景过程」而非结论。
  - 思考中自动展开；回答文本开始流式时立即收起（不再等整个回合结束）；思考若恢复则重新展开。
  - 手动开合优先：自动收放只在相位跳变时触发一次（思考→完成 / 完成→思考），逐事件不再覆盖，用户点开的面板不会被关上。
  - 不思考的模型不留空面板（中途与终态都有测试覆盖）。
- **对话框可拖拽调整大小**：抓住右下角拖动。
  - 浮窗锚定右下角，向左上拖=变大；独立页向右下拖=变宽变高。
  - 尺寸存 localStorage，刷新保留；双重夹取（下限 300×360 / 360×420，上限按视口实时计算），窗口缩小后自动夹回，绝不留下够不着的面板。
  - 键盘可达：抓手可聚焦，方向键微调。隐私模式（无 localStorage）只失去记忆功能，拖拽照常。

### 质量

- 新增行为测试全部驱动真实页面脚本 + 真实 fetch/SSE 流与 pointer 事件（页面通道 10 条 + resize 8 条 + 浮窗通道 5 条）；变异验证 6 组全红。
- **后台任务推送按来源标注 + 「前台执行」逃生门**：推送头跟随 origin_note（聊天转派→后台任务，挖掘/提案→自主任务）；「前台执行」可撤回本人转派的排队/已计划任务并内联重跑原始指令（仅创建人、执行中拒绝以防双重执行、重跑跳过分诊）。
- 110 个测试套件全绿；不可变内核（16 区）未动。
