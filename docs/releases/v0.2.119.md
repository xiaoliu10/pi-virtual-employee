## 0.2.119

### 改进

- **模型切换入口显性化**（现场反馈：客户端找不到切换模型的地方——「设为默认」按钮藏在 hover 才出现的 ★ 里，失败提示写的「设置 → 模型」与实际页面名也对不上）：
  - 设置 → 自定义模型页顶部新增**常驻「当前默认」切换条**：下拉框列出全部启用供应商的模型（供应商名 / 模型 ID），选中即切换员工对话与自主任务使用的默认模型——不再需要进供应商详情找 hover 按钮；
  - 供应商详情里的 ★ 按钮改为**常显的「★ 设为默认」按钮**（不再 hover 才出现）；
  - 模型无返回卡住的推送指引同步改为真实路径：「设置 → 自定义模型 顶部把其他供应商的模型『设为默认』」。
