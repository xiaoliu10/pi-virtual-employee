## 0.2.125

### 修复

- **联网研究对存量部署默认打开**：0.2.123 只改了新配置的默认值，老配置里已落盘的 `kb.research: {enabled:false, engine:"duckduckgo"}` 会让升级后的部署保持关闭——现场（及多数存量部署）正是这个状态。本版加一次性迁移：检测到这个「从未被用户选择过」的老状态（false + duckduckgo）时自动翻转为 `{enabled:true, engine:"bing"}` 并持久化；判据为 engine 仍是 legacy duckduckgo：**0.2.123/124 窗口期内曾显式关闭研究（写 enabled:false 但 engine 未动）的配置会被一并翻转**——如确不想要，升级后再关闭一次即可（`manage_capabilities set research off`，写 bing+false 后不再被迁移）。显式换成 bing/custom 引擎的选择不受影响。
- 管理员完全访问（security.adminFullAccess）**保持不变**：仍由管理员手动开启一次（非对称门控：开难关、关闭易）。
