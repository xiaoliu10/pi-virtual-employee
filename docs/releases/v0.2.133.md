## 0.2.133

### 变更：模型配置页改为 pi Desktop 同款（复用参考实现）

- 输入类型控件换成 pi Desktop 模型配置对话框的**复选框芯片**同款交互与结构（`[✓ 文本（固定）] [☑ 图片]`），不再自定义三态按钮组；
- 图片勾选 = 强制声明支持图片，取消 = 强制关闭；「恢复默认」回到继承模型注册表的基础能力。声明应与服务商提供的模型一致；
- 模型行上的图片复选框同款风格，直改路径保留（勾选 = 强制声明、取消 = 强制关闭；从强制指定回到继承需进对话框点「恢复默认」，行内 tooltip 与说明文字均已给出该路径）；
- 语义抽成纯函数（resolveImageChecked / nextModelImage）+ 5 组状态迁移单测（test-model-image），pin 死三态映射；
「显示名称 / 推理等级」等参考页字段因本应用引擎不消费，按「能力/配置镜像」原则不引入。
