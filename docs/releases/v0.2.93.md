## 0.2.93

### 新特性

- **模型最大输出三级解析**：单次回复的输出上限按「模型配置覆盖 → 供应商网关 model-info 接口（litellm `/model/info`，每次运行查询一次并缓存）→ 静态默认（中转 32K）」的顺序解析。此前未配置时会静默继承注册表值（如 131072），对中转网关后的模型是虚构值——输出预约 alone 就能挤爆上下文窗口（现场：litellm qwen 73729 输入 + 131072 输出 > 204800 窗口，恰好超 1 个 token 被拒）。
- **run_command 放开「仅限单聊」**：群聊可直接执行命令（现场：SLS 排障需要在任务所在的群里跑脚本）。安全门一道不少：平台验证发送者、角色分级（operator 白名单 / admin 全量）、当前消息「确认」、会话隔离与审计日志全部照旧。其他特权管理工具（改配置/改权限）维持单聊要求。

### 修复

- **上下文闸门扣减输出预留**：压缩阈值与轮内预算改按「窗口 − 输出上限」计量（下限窗口/4），与供应商的 `输入+输出 ≤ 窗口` 约束对齐；否则闸门放行注定被网关拒绝的输入量。
- 网关返回的输出上限钳制在窗口内（误报防御）；未知形状的 model-info 响应一律视为无信息、绝不造值。

> 升级提示：装上本版后，中转模型无需手动配置输出上限——应用会向网关自动查询；如需覆盖仍可在设置页「最大输出 Token」或 `manage_settings` 的 `modelMaxTokens` 指定。
