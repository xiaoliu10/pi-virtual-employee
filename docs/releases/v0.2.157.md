# v0.2.157

## 修复：心跳进度汇报中的记忆前缀残留（#102）

- 对带记忆块开头、但缺少结束标记的文本保守剥离，避免把「本回合自动携带的个人/本群记忆…」当作当前请求显示。
- 统一字符串与多模态文本部分的合成消息判定：完整纯记忆块和不完整记忆块不再作为真实任务锚点；记忆块后面的真实请求继续保留。
- 这是对不完整记忆块的防御性保护。已复现这类输入会触发旧版泄漏，但尚未定位现场不完整输入的来源，不宣称已根治所有现场原因。

## 新增：IM `/reload` 命令（#101）

- 单聊或群聊 @机器人 发送 `/reload`，直接重新加载磁盘上的技能列表，并回复当前技能数量；`/help` 同步更新。
- 不清空上下文、不重启应用、不打断其他正在运行的回合；新技能从后续消息起生效。同一会话有任务运行时，该命令按原有会话队列等待执行。
- 支持全角斜杠、@提及粘连和大小写变体；不把 `/reloads`、`/reloadx` 当作命令。
- 仅刷新技能，不安装浏览器、不升级应用，也不强制重建知识库。
