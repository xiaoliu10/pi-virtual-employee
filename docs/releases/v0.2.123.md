## 0.2.123

### 新增：联网研究开箱即用（现场反馈「应该支持 web_search 去网络上查资料」）

- `research_web` 联网搜索工具其实早已内置（知识库未命中时联网查资料→沉淀知识），但默认关闭、且默认引擎 DuckDuckGo 在中国大陆不可达——员工因此回复「我没有联网搜索工具」。本版三项修复：
  1. **默认开启**：`kb.research.enabled` 默认 true（新部署开箱即用；已保存过配置的部署保持原值，可在对话里用「开启联网研究，确认」或 设置 里打开）。
  2. **默认引擎改为 Bing**（`kb.research.engine: "bing"`）：免 API Key、中国大陆可达；解析 b_algo 结果块，带 15 秒超时，失败如实返回空结果不编造。原 duckduckgo 与自定义 HTTP 端点（SerpAPI/SearXNG 等）引擎保留。
  3. **权限解耦**：`research_web` 的能力门槛从「浏览器操作」改为「知识库检索」——联网搜索不需要给员工开浏览器权限。
- 管理开关新增入口：`manage_capabilities set research on/off`（管理员 + 确认，或完全访问直接执行），桌面设置页能力列表同步显示。
- 权限变化披露：`research_web` 现挂「知识库检索」门槛（viewer 即可用）——对曾用「浏览器操作」floor 间接限制联网研究的部署，升级后该限制不再覆盖 research_web（如需单独收紧可抬 knowledge floor，但会连坐知识库检索）。观察项：Bing 免 key HTML 抓取属 best-effort，若遇反爬拦截会如实返回空结果；高频场景建议改配 `kb.research.engine: "custom"` 对接自建搜索端点。
