## 0.2.92

### 修复

- **调度器停摆根因修复**：单次定时任务运行新增硬超时（默认 60 分钟）。此前一个永不结束的任务运行会永久占住调度互斥锁——所有定时任务停止触发，而应用其他功能看起来正常。现在挂死的运行只会在超时后被记为失败（`error:run_timeout`），调度器继续运行后续任务。
- **定时任务推送目标保护**：在单聊里修改一个群聊创建的任务细节，不再可能把推送目标静默改绑到单聊。推送目标由创建时明确指定；改绑已有目标现在需要当前消息包含「确认」，且每次修改的回显会明确说明「推送目标未变」。
- **长任务心跳汇报升级**：旁路进度总结与兜底文案都改为目标级汇报——归纳阶段性成果，不再把「打开某后台页、调整分页」这类底层执行细节原样推给用户。

### 其他

- 新增英文版 README（`README.en.md`），中文版顶部加双语入口。
- 发布流程升级：每个版本同时发布 Windows 安装包与 macOS (Apple Silicon) dmg 到 GitHub Releases；Gitee `latest` 继续作为 Windows 自动更新源。
