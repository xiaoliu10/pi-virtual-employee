# 0.2.147（2026-10-14 发布）

## 变更一：消息与遥测保留策略（#78）

- 新增 `general.messageRetentionDays`，默认 **30 天**，`0` 表示关闭自动清理。
- 超龄后删除 VE SQLite 中的消息正文、turn 遥测与工具调用遥测；**会话条目保留**，任务列表与入口不会因历史消息清理而消失。
- 应用启动与保存配置后执行；设置页「通用」与 `manage_settings` 均可配置。
- 本项只管理 VE 自己的 `pi-employee.sqlite`，不清理 pi CLI 的 JSONL 会话文件。

## 变更二：自动更新下载韧性与多 profile 安全（#79、#80，现场驱动）

- 针对 Windows 自动更新日志中的 `ENOENT rename temp-Pi-Virtual-Employee-Setup-*.exe`，保留文件锁/rename 类下载失败的有限自动重试：**30 秒、2 分钟、10 分钟，最多 3 次**，之后等待下一个 6 小时检查周期。
- 下载失败不再写入「安装失败」熔断器：下载尚未完成时不应污染安装健康统计，避免网络恢复后正常安装包被误拦。
- 明确移除应用层对 electron-updater **共享缓存**的主动删除：Nova/Orion 是不同进程，但共用用户级更新缓存，一个实例失败不能证明另一个实例的临时文件可删。electron-updater 失败路径自身会清空 `pending/`，硬退出残留也会在下次创建临时文件时处理。
- 检查更新与下载/挂起重试互斥；每次新的更新检查开启新的有限重试窗口；应用退出时取消挂起重试。
- `-4082` 网络中止不再触发 97MB 安装包的重复全量下载。
- 新增 8 个下载重试策略测试。
