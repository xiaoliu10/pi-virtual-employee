## 0.2.136

### 修复：卡点也会沉淀了——中断/暂停/出错的自动学习轮（现场质疑「自动总结系统没有生效吗」）

- 根因确认：自动沉淀此前**只挂在任务完成（done）上**，而反复卡死的任务永远到不了 done——自动总结对最需要它的任务恰好从不触发；stalled 提示文案里「恢复成功后我会把现象与解法沉淀进知识库」是未兑现的承诺；
- 修复：**所有结局都跑收尾学习轮**——done 总结可复用经验；stalled / 等待人工 / 预算用尽 / 出错则记录卡点（卡在哪一步、已尝试什么、现象要点、下次恢复建议）写入知识库；
- 恢复任务时强制先检索：pending 链恢复的第一轮自动注入「先 kb_search 本次卡点相关经验，已有解法直接应用，不要重复无效尝试」——沉淀和取用两头接通；
- 现场背景：游戏小派卡在截图传递多轮。截图这步它早就会了（mumu-cli 成功多次），「把图传给模型」在 0.2.135（view_image）之前根本不存在——工具缺失不是总结能救的；升级 0.2.135+ 并在设置里勾选模型「图片」后，截屏 → view_image 即可真实识图。
