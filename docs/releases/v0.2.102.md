## 0.2.102

### 新特性

- **管理员在群聊直接对话升级**（用户诉求：直接和 Nova 对话就能让它自己重启升级，类似无人值守自动升级）：`manage_update` 放开「仅限单聊 + 每次确认」的门禁——任意聊型的平台验证管理员直接执行 `status` / `check` / `update` / `set_auto`（沿用 2026-09-23 放开单聊、2026-09-29 管理员发起即授权两条裁定）。`action=update` 下载并登记空闲重启：不中断进行中的任务，等全部任务空闲后自动重启进安装器。破坏性的 `install_now`（立即结束任务并重启）仍需当前消息明确「确认」。管理员在群里说「升级到最新版」即可完成整个升级流程。
