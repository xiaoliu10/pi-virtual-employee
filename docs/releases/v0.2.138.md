## 0.2.138

### 修复：从账号目录移除「OpenAI（ChatGPT 后端）」死路条目（现场：openai 登录后模型列表选不到）

- 核查 pi-ai 注册表：**「OpenAI（ChatGPT 账号）」（openai-codex）注册正常**，模型齐全（gpt-5.5 / gpt-5.6-* / gpt-6-* 等）——0.2.134+ 登录成功即自动进模型列表（重登一次可补建）；**「OpenAI（ChatGPT 后端）」（openai-chatgpt）在 pi-ai 从未注册**——登录直接报 Unknown provider，模型列表永远为空，是纯死路；
- 处理：把 openai-chatgpt 从账号目录移除（pi-ai 注册后再加回）。选「ChatGPT 账号」登录的用户不受影响；
- 「ChatGPT 账号」（openai-codex）用户注意：账号登录自动进模型列表需要 **0.2.134+**（登录成功时自动建供应商条目）——在旧版本上登录过、之后才升级的部署，请**退出登录重新登录一次**（或在 设置 → 自定义模型 → 目录 登录后点「添加为模型供应商」）；
- 存量清理（罕见）：若 设置 → 自定义模型 里存在名为「OpenAI（ChatGPT 后端）」的空条目（升级后首次启动会被剥掉账号关联、不再产出模型），手动删除即可。
