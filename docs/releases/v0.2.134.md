## 0.2.134

### 修复：账号登录后，该供应商的模型进入模型列表（现场反馈「openai 账号登录之后选不到对应模型」）

- 根因：「设置 → 账号登录」入口的登录流程只写凭据、不创建供应商条目，而模型下拉/切换条枚举的是 config 供应商列表——登录成功但模型永远不出现。此前只有「自定义模型」页里的目录登录流程会建条目；
- 修复：登录成功时引擎自动确保该 authProvider 的供应商存在——已禁用则重新启用、不存在则以稳定 ID（auth-\<provider\>）创建（模型列表留空，pi-ai 注册表仍是该类供应商的唯一模型来源）；
- 幂等：重复登录不产生重复条目；登录失败/取消不建条目；确保失败不阻塞登录本身（可手动从目录添加兜底）；
- 新增 2 个引擎测试：登录建条目→下拉可见注册表模型；幂等与禁用复活。
