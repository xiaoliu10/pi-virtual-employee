# v0.2.150

## 收尾验证插件 + 任务边界修复（三个现场问题闭环）

### 新增

- **ve-settle-gate 证据轮自证插件**（#84 verify-gate 以插件形式重新交付）：内核迁移后扩展运行时已通，verify-gate 改为 pi inline extension 形态。`[[TASK_DONE]]` → 系统强制一轮证据式验证（逐条对照目标、用工具重新核实、给证据）→ `[[VERIFY_PASS]]`+tool 证据才 settle；FAIL 自动修复轮；连续 2 轮 FAIL 放行 + ⚠️ 显式报告（防死循环）。vendor 决策核心对齐 pi-quality-gates（`SettleGateState`/`decideSettle`），发 npm 后换真依赖。
- **自主任务一步创建入口**（`manage_work_items` action=create）：管理员说「重建自主任务」时一步建 work item（入队开工、created_by 跟随创建人），不再需要 mine→confirm 两步。

### 修复

- **「自主任务变成定时任务」现场问题（两次复发）**：根因三缺口——① work item 无一步创建入口；② `create_scheduled_task` 的 `autonomous` 参数名直译「自主模式」造成术语撞车；③ 铁律只覆盖 waiting_human 场景。修复：补 create 入口 + 两处工具描述钉死术语边界（**自主任务=work item，员工自决节奏无 cron；定时任务=create_scheduled_task 到点执行**；autonomous 参数只是「到点后多跑几轮」仍是定时任务）+ waiting_human 回合禁止新建任务顶替的铁律。
- **客户端不能改任务**：设置页任务 tab 补编辑能力——定时任务编辑弹窗（标题/cron/指令，validateCron 校验 + next_run 重算）；自主任务编辑目标/条件弹窗 + 暂停/恢复/取消按钮（终态不显示）。新 IPC：`tasks:schedEdit`/`tasks:workAct`/`tasks:workEdit`。
