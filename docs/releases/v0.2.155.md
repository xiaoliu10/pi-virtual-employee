# v0.2.155

## IM 凭据出站门禁

修复员工在群聊排查登录故障时可能明文回复账号密码的问题：在消息发送链路增加代码级检测，不再仅依赖提示词约束。

- **群聊一律拦截命中的凭据文本**，即使提问者是管理员；非管理员或身份不明的单聊同样保守处理。已验证管理员单聊可获取原文，撤权后下次发送即生效。
- 覆盖最终回复、交互卡片正文/预览/复制字段、Markdown 回退、进度消息和主动推送；长推送先扫描全文再拆分，避免拆分边界漏检。
- 支持中英文密码/密钥标注与多种常见凭据格式；命中后整条替换为安全提示，普通的“密码是否变更”等提及不受影响。
- URL 查询参数中的分享令牌就地打码，保留报告正文；被打码的链接不再具有原令牌授权能力，需通过有权限的渠道访问。
- 不影响员工内部使用凭据登录、填写表单等操作。

### 检测边界

这是启发式文本门禁，不是完整 DLP。文件/图片内容及文件名、媒体 URL 不在本次检测范围；未标注的自由文本、以空格拆开的值、短数字密码和验证码等仍可能未命中，也可能出现保守误拦。请勿将其视为所有凭据均不会泄露的保证。

### 验证

新增凭据出站测试套件，覆盖策略、适配器真实请求 payload、管理员撤权、主动推送和卡片失败回退。发布前执行全量测试、typecheck、build、不可变区域校验及 diff 检查；最终结果记录于 PR #95。
