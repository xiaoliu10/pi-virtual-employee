# v0.2.184 — Work gates accept owner / progress notes push / per-model thinking levels

发布日期：2026-11-02

## English

**Owner-created autonomous work no longer bounces back to "awaiting human" (P0)** — the WorkService window gate was a separate inline check that still compared `role === "admin"` literally, so owner-created work items passed creation and then EVERY execution window bounced back to `waiting_human`. Field loop: resume → "re-queued" → bounced again. Both gates now share `isDeclaredAdmin()` (explicit declaration + rank ≥ admin); credential egress deliberately keeps the live `isAdmin()` (honours `defaultRole`).

**Autonomous-task progress notes actually push again** — every side-pass summary died with `generation hit the token cap`: the 512-token reserve (409 after pi-ai's 0.8 factor) is shared by thinking and the answer, and default-thinking qwen consumed it all. Reserve is now 4096 (still clamped by model max tokens).

**Per-model thinking levels** — 设置 → 模型 → 思考档位 per model: `off/minimal/low/medium/high/xhigh/max`. Relay suppliers (hand-entered baseUrl) take the declaration as capability truth; account-login suppliers keep registry capability and the declaration only sets the requested level. `off` strips to "no level" (a literal `off` forces thinking ON on Anthropic-API models and can yield `max_tokens: null`); unsupported levels degrade automatically via pi-ai `clampThinkingLevel`; undeclared models behave exactly as before.

Guardrails: `rbac-gate` (src/security/permissions.ts) re-pinned with IMMUTABLE_ACK — new `isDeclaredAdmin()` pure function added; no existing conclusion changed.

Verification: 79 test suites + dual tsconfig typecheck + immutable 16 regions + build, all green on the merged main; behavioral payload probes (real `streamSimple` + `onPayload`) across four independent review rounds; 6 mutations all falsifiable.

## 中文

**owner 创建的自主任务不再反复打回「待人工恢复」（P0）**——WorkService 窗口门禁是另一段内联判断，仍按 `role === "admin"` 字面比较，owner 创建的任务创建成功后**每个执行窗口**都被打回 `waiting_human`。现场循环：恢复 → 已重新入队 → 又被打回。两处门禁收敛到 `isDeclaredAdmin()`（显式声明 + rank ≥ admin）；凭据外发保持实时 `isAdmin()`（尊重 `defaultRole`）。

**自主任务进度汇报恢复推送**——旁路总结全部死于 `generation hit the token cap`：512 token 预留（折算 409）被思考与正文共享，默认开思考的 qwen 一段 120 字汇报就能吃满。预留提到 4096（仍受模型 max tokens 钳制）。

**每模型思考档位**——设置 → 模型 → 思考档位：`off/minimal/low/medium/high/xhigh/max`。中继型供应商以声明为能力真源；账号登录型保持 registry 能力、声明只设请求档位。`off` 剥离为「无档位」（字面 off 在 anthropic API 模型上会强制开启思考、甚至产生 `max_tokens: null`）；不支持的档位自动降级；未声明模型行为完全不变。

护栏：`rbac-gate`（src/security/permissions.ts）以 IMMUTABLE_ACK 重钉——新增 `isDeclaredAdmin()` 纯函数，不改变任何既有结论。

验证：合并态 main 上 79 套件 + 双 tsconfig typecheck + immutable 16 区 + build 全绿；四轮独立 review 的 payload 级行为探针（真实 `streamSimple` + `onPayload`）；6 个变异全部可证伪。

## 升级后现场操作

- owner 创建的自主任务仍在「待人工恢复」的：管理员在来源会话回复一次恢复内容即可，之后每个窗口自动开工。
- 想要四段式进度汇报：无需配置（默认已修）；如需控制思考强度，在设置页模型编辑里选思考档位。
