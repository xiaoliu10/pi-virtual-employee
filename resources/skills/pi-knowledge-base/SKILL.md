# 知识库查询

## 何时使用
- 客户询问售后政策、退款、发货、运费、发票、保修、产品规格等**事实性**问题。
- 你不确定或无法从上下文确认的规则、流程、口径。
- **先查后答**：回答这类问题前，必须调用 `search_knowledge_base(query)`，以返回结果为准；不要凭记忆编造。
- 知识库未命中时，明确告知“暂未收录”，并按需要转人工或建议联系渠道。

## 如何外接知识源（面向管理员配置）
内置知识库支持本地条目与导入文档。若需要接入外部知识，可在设置中：
1. **HTTP 接口**：把外部检索服务封装成一个新的工具（`AgentTool`），在 `buildTools` 中挂载；或在本知识库里新增条目说明调用方式。
2. **MCP**：将 MCP server 暴露的工具加入员工工具集，模型即可像调用普通工具一样调用。
3. **文档导入**：在「设置 → 知识库与技能」导入 TXT/Markdown/PDF，系统自动分块并纳入全文检索。

## 检索结果处理
- 结果中的 `【…】` 为命中高亮片段；优先采纳命中度高、来源权威的片段。
- 多条命中时综合归纳，避免逐条堆砌；引用关键数字/时限时要准确。
